# fIZZY - Interactive 3D Landing Page

## Project Overview

fIZZY is an interactive 3D landing page created to showcase **Spline Hana** for the **Contra x Spline Challenge**. This project demonstrates the incredible capabilities of modern web-based 3D design tools.

> **Note:** This is a showcase project - fIZZY is not a real product!

## 🎨 Built for the Contra x Spline Challenge

This project was created to demonstrate:
- The power of **Spline Hana** for web-based 3D design
- Smooth scroll-triggered animations
- Interactive 3D product visualization
- Modern web development techniques

## Tech Stack

- **Frontend Framework**: Next.js
- **3D Graphics**: React Three Fiber, Three.js
- **3D Design**: Spline Hana
- **Animation**: GSAP (GreenSock Animation Platform)
- **Styling**: Tailwind CSS

## Key Features

### 🎯 3D Visualization
- Interactive 3D soda can models
- Custom 3D scenes with floating and animated elements
- Responsive canvas rendering across devices

### ✨ Smooth Animations
- GSAP-powered scroll-triggered animations
- Text and character-level animations
- 3D object transformations

### 📱 Responsive Design
- Works beautifully on desktop and mobile
- Optimized performance across devices

## The Workflow

This landing page showcases the workflow of building 3D web experiences with Spline:

1. **Starting with Spline Hana** - Exploring the powerful 3D capabilities
2. **Designing the Can Models** - Crafting realistic materials and lighting
3. **Adding Smooth Interactions** - Creating scroll-based animations
4. **Final Polish & Export** - Optimizing and integrating into Next.js

## Getting Started

### Prerequisites
- Node.js
- npm or yarn

### Installation
```bash
git clone https://github.com/HammadArifeen/Spline-Contra-Challenge.git
cd Spline-Contra-Challenge
npm install
npm run dev
```
